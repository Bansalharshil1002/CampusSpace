# Week 3 -- Mansi (Frontend)

## Integration, Testing & Debugging

### Work Done

-   Tested the complete frontend workflow with the backend.
-   Checked room information, status display, and user interactions.
-   Tested different room statuses and role-based actions.
-   Helped identify UI and integration issues during testing.
-   Coordinated with the backend team to verify that displayed
    information matched the database data.
-   Refined the interface based on testing results.

### Key Observations

Complete-system testing was necessary because individual frontend
components could work correctly while still having problems when
connected to backend services.

### Issues Faced

-   Some issues appeared only after frontend-backend integration.
-   Role-based actions required testing with multiple user scenarios.
-   Status information needed to remain consistent between the interface
    and backend.

### Solution / Outcome

The frontend was refined and tested as part of the complete Room Status
Tracker workflow.
