# Week 1 -- Mansi (Frontend)

## Understanding the Problem Statement & Planning

### Work Done

-   Reviewed the problem statement and discussed the expected user
    experience.
-   Identified the information that should be visible for rooms and
    their current statuses.
-   Discussed possible user interactions for viewing and updating room
    information.
-   Helped identify the major frontend components and divide
    responsibilities within the frontend pair.
-   Coordinated with the backend team regarding users, roles, room
    information, and status data.

### Key Observations

The interface needs to make room status easy to understand while keeping
actions appropriate for each user role.

### Issues Faced

-   Some frontend requirements depended on decisions about backend data
    and permissions.
-   It took time to understand the different room types and how their
    statuses should be displayed.
-   The team needed to agree on a common workflow before development
    could begin.

### Outcome

A basic frontend plan and workflow were established, and the team was
ready to begin implementation.
