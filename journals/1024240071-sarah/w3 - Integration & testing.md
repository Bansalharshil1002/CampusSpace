# Week 3 -- Sarah (Frontend)

## Integration, Testing & Debugging

### Work Done

-   Connected the main frontend workflows with the backend.
-   Tested viewing rooms and their current statuses.
-   Tested frontend interactions related to room status updates.
-   Checked how different user roles affected available actions.
-   Worked with the backend pair to identify and resolve integration
    issues.
-   Refined the interface based on issues found during testing.

### Key Observations

Most integration issues occurred at the point where frontend actions
depended on backend validation and data.

### Issues Faced

-   Some backend responses required corresponding frontend adjustments.
-   Different permissions and room types needed to be tested through the
    interface.
-   Debugging was sometimes dependent on understanding whether an issue
    originated in the frontend or backend.

### Solution / Outcome

The frontend was integrated with the main backend workflows and tested
using different user and room scenarios.
