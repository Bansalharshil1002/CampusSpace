# Week 2 -- Sarah (Frontend)

## Frontend Development

### Work Done

-   Started developing the frontend interface for the Room Status
    Tracker.
-   Worked on the main room-related views and user interactions.
-   Planned how room names, room types, and current statuses would be
    displayed.
-   Started connecting frontend actions with the required backend
    functionality.
-   Coordinated with the backend pair to ensure the frontend used the
    expected data structure.

### Key Observations

The frontend depended on consistent backend responses, particularly for
room information and status data.

### Issues Faced

-   Some interface decisions had to be adjusted as backend functionality
    became available.
-   Connecting frontend actions to backend operations required testing.
-   Different room types and statuses required appropriate handling in
    the interface.

### Outcome

The main frontend structure was established and initial backend
integration was started.
