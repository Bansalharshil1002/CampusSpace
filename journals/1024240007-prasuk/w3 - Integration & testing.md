# Week 3 -- Prasuk (Backend)

## Integration, Testing & Debugging

### Work Done

-   Tested the room management functionality developed during Week 2.
-   Checked room creation, listing, activation, and deactivation
    workflows.
-   Tested database operations and validation for room data.
-   Worked with Harshil to test interactions between room, assignment,
    and status services.
-   Helped debug issues discovered during integration with the frontend.

### Key Observations

Testing individual services separately was easier than testing the
complete application. Integration testing was important for finding
issues between components.

### Issues Faced

-   Some problems appeared only when frontend and backend components
    were connected.
-   Validation and database-related edge cases required additional
    testing.
-   Changes in one service sometimes affected dependent functionality.

### Solution / Outcome

The room-related backend functionality was tested and refined, and
integration issues were addressed as they were discovered.
